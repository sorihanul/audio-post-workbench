# 노래 후보정 워크벤치

설치 없이 쓰는 초보자용 노래 후보정 도구입니다.

브라우저에서 오디오 파일을 불러와 위험 구간을 확인하고, 보수적인 보정을 만든 뒤 원본과 보정본을 비교하고 WAV로 저장할 수 있습니다.

## 사용법

Chrome 또는 Edge에서 `index.html`을 여세요.

Windows에서는 아래 파일을 더블클릭해도 됩니다.

```text
RUN_AUDIO_WORKBENCH.bat
```

다운로드해서 사용할 때는 서버, Python, Node.js, 계정, API 키, 인터넷 연결이 필요 없습니다.

## 주요 기능

- 오디오 파일을 브라우저 안에서 로컬로 불러오기
- 최대 소리, 평균 소리, 찢어짐 위험, 먹먹함, 날카로움, 좌우 밸런스, 모노 위험, 앞/끝 무음 확인
- 다시 들어볼 구간 표시
- 보수적인 추천 보정 만들기
- 초보자용 소리 개선 목표 제공
  - 자동
  - 보컬 또렷
  - 먹먹함 정리
  - 귀 피로 줄이기
  - 분리감 살리기
- 원본/보정본 A/B 비교
- 보정본 WAV 저장

## 개인정보

오디오 파일은 브라우저 안에서 처리됩니다. 이 앱은 오디오 파일을 외부로 업로드하지 않습니다.

## 한계

전문 믹싱/마스터링 프로그램을 대체하지 않습니다.

이 도구는 초보자가 소리를 과하게 망치지 않도록 돕는 안전 후보정 도구입니다.

AI 보컬 분리, 악기 분리, 전문 마스터링 기능은 없습니다.

## 권장 브라우저

최신 Chrome 또는 Edge를 권장합니다.

오디오 형식은 WAV와 일반 MP3가 가장 안전합니다.
