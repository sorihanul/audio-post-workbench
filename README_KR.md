# 노래 후보정 워크벤치

설치 없이 쓰는 초보자용 노래 후보정 도구입니다.

브라우저에서 오디오 파일을 불러와 위험 구간을 확인하고, 보수적인 보정을 만든 뒤 원본과 보정본을 비교하고 WAV로 저장할 수 있습니다.

## 사용법

Chrome 또는 Edge에서 `index.html`을 여세요.

Windows에서는 아래 파일을 더블클릭해도 됩니다.

```text
RUN_AUDIO_WORKBENCH.bat
```

다운로드해서 사용할 때는 서버, Python, Node.js, 계정, API 키, 인터넷 연결이 필요 없습니다.

## 빠른 사용 순서

1. 앱을 엽니다.
2. 오디오 파일을 선택합니다.
3. 메인 탭에서 자동 점검을 누릅니다.
4. `의심 구간 자동 선택`을 누릅니다.
5. 메인 탭에서 보정 만들기와 저장까지 진행합니다.
6. 필요할 때만 `설정`, `구간 확인`, `보정 결과`, `비교`, `해설` 탭을 엽니다.

## 사용 가이드라인

- 첫 보정은 보수적으로 쓰는 것이 좋습니다. 이 도구는 믹스를 크게 바꾸는 도구가 아니라 뚜렷한 위험을 줄이는 보조 도구입니다.
- 표시된 위험 구간은 헤드폰이나 믿을 만한 스피커로 다시 들어보세요.
- 보정본이 작아지거나, 답답해지거나, 찢어지거나, 귀가 피곤하면 원본을 유지하거나 더 약한 목표를 쓰세요.
- 저장한 파일을 다시 여러 번 보정하지 않는 것이 좋습니다. 이미 보정된 파일을 반복 처리하면 음질 손상이 커질 수 있습니다.
- 원본 파일은 반드시 따로 보관하세요. 저장되는 WAV는 새 파일이지만 원본을 대체하면 안 됩니다.
- 중요한 공개 음원이라면 이 도구는 빠른 보조용으로만 쓰고, 실제로 들을 환경에서 다시 확인하세요.

## 주요 기능

- 오디오 파일을 브라우저 안에서 로컬로 불러오기
- 메인, 설정, 구간 확인, 보정 결과, 비교, 해설 탭으로 화면 분리
- 최대 소리, 평균 소리, 찢어짐 위험, 먹먹함, 날카로움, 고역 꼬리, 좌우 밸런스, 모노 위험, 앞/끝 무음 확인
- 좌우 위상/모노 손실을 바탕으로 작은 스피커 위험 확인
- 파형 위에 다시 들어볼 구간 표시
- 큰 영역 우선 확인, 필요할 때만 선택 영역의 세부 구간 펼치기
- 구간 듣기 시 구간 끝 자동 멈춤 켜기/끄기
- 의심 구간 자동 선택, 보정 만들기, 저장을 한 곳에서 처리
- 짧은 고역 찌름 후보의 세부 위치 표시
- 작은 스피커에서 힘이 빠질 수 있는 구간 표시
- 구간별 안전 보정
  - 튀는 구간 응급처치
  - 귀 아픈 구간 완화
  - 고역 꼬리 완화
  - 해제
  - 앞뒤 연결부 자동 완화
- 보수적인 추천 보정 만들기
- 초보자용 소리 개선 목표 제공
  - 자동
  - 보컬 또렷
  - 먹먹함 정리
  - 귀 피로 줄이기
  - 분리감 살리기
- 원본/보정본 A/B 비교
- 원본과 보정본의 사운드 상태를 문장으로 풀어주는 로컬 해설
- 보정본 WAV 저장

## 개인정보

오디오 파일은 브라우저 안에서 처리됩니다. 이 앱은 오디오 파일을 외부로 업로드하지 않습니다.

## 한계

전문 믹싱/마스터링 프로그램을 대체하지 않습니다.

이 도구는 초보자가 소리를 과하게 망치지 않도록 돕는 안전 후보정 도구입니다.

AI 보컬 분리, 악기 분리, 전문 마스터링 기능은 없습니다.

분석 수치는 실용적인 힌트이지 최종 판정이 아닙니다. 실제 청감과 올릴 플랫폼 기준을 함께 봐야 합니다.

## 권장 브라우저

최신 Chrome 또는 Edge를 권장합니다.

오디오 형식은 WAV와 일반 MP3가 가장 안전합니다.

## GitHub Pages

정적 HTML 앱이라 GitHub Pages로 바로 공개할 수 있습니다.

Pages를 켜면 사용자는 URL만 열어서 사용할 수 있습니다.

권장 Pages 설정:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```
